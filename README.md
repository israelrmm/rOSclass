# rOSclass
A modern, lightweight PHP class optimized for the RouterOS/Mikrotik native API


[![PHP 8.2+](https://img.shields.io/badge/PHP-8.2+-777BB4)](https://php.net)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![MikroTik](https://img.shields.io/badge/MikroTik-RouterOS-orange.svg)](https://mikrotik.com/)

A lightweight, fast, and optimized PHP library designed to interact with the **MikroTik RouterOS** API. Based on the original work by Denis Basta and enhanced for modern development environments with strict typing and SSL support.

## ✨ Features

* **2026 Optimization:** Refined code for PHP 8.2 and higher (fully compatible with PHP 8.x).
* **Security:** Native support for secure connections via **SSL/TLS**.
* **Compatibility:** Works with RouterOS v6.43+ (new login method) and legacy versions.
* **Debugging:** Integrated debug system to monitor API communication directly in the console.
* **Flexibility:** Simplified methods for executing direct commands or using parameter arrays.

---

## 🚀 Installation

Simply download the `ros.class.php` file and include it in your project:

```php
require_once 'ros.class.php';
```
